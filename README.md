# OpenWrt Service Toolkit

Интерактивный скрипт-комплект для выбора и установки сетевых инструментов на OpenWrt. Устанавливает только отмеченные компоненты и по возможности устанавливает русские пакеты интерфейса LuCI.

## Запуск

Подключитесь к роутеру по SSH под пользователем `root` и выполните:

```sh
wget -O /tmp/openwrt-toolkit.sh https://raw.githubusercontent.com/TMN88/router-service-check/main/openwrt-toolkit.sh && sh /tmp/openwrt-toolkit.sh
```

Скрипт предложит выбрать компоненты, затем покажет выбранный список до установки.

## Компоненты

- **Podkop** — маршрутизация выбранного трафика через прокси/VPN: [itdoginfo/podkop](https://github.com/itdoginfo/podkop).
- **AmneziaWG** — установка пакетов без настройки и включения туннеля: [Slava-Shchipunov/awg-openwrt](https://github.com/Slava-Shchipunov/awg-openwrt).
- **Zapret Manager** — панель управления: [StressOzz/Zapret-Manager](https://github.com/StressOzz/Zapret-Manager).
- **Zapret2 от Routerich** — установка пакетов и базовых файлов конфигурации из Zapret Manager. Требует подходящую архитектуру `aarch64_cortex-a53`; обычный Zapret и Zapret2 нельзя использовать одновременно.
- **AWG Test / Podkop VPN Failover** — проверка VPN-туннелей и переключение резервных интерфейсов: [SVTagan/podkop-vpn-failover](https://github.com/SVTagan/podkop-vpn-failover). Официальный установщик проекта в текущей версии требует `opkg`, поэтому скрипт пропускает его на OpenWrt 25.12 с `apk`.
- **Site Checker** — LuCI-приложение проверки доступности сайтов: [TMN88/Site_Checker](https://github.com/TMN88/Site_Checker).

## Важные замечания

- Скрипт использует установщики и исходные файлы указанных проектов; это не объединённый пакет и не форк перечисленных приложений.
- Русские переводы устанавливаются, если соответствующий пакет доступен в настроенных feeds или в исходном установщике.
- Установщик AmneziaWG запускается без настройки туннеля, поэтому не создаёт интерфейс и не перенаправляет трафик.
- Zapret2 из пакетов Routerich — только для подходящей платформы/архитектуры и поддерживаемого выпуска OpenWrt. Пакеты стороннего feed могут быть неподписанными, поэтому внимательно проверяйте источник.
- Запускать установщики сторонних проектов нужно с правами root. Перед установкой сохраните конфигурацию роутера.


## Локализация

Скрипт старается автоматически включать русский язык LuCI там, где перевод доступен. Системные сообщения самих сторонних установщиков могут оставаться на английском. Опасные действия — удаление конфликтующих пакетов или миграция существующей конфигурации — автоматически не подтверждаются.

## Совместимость

Основной расчёт — OpenWrt 24.10 (`opkg`) и 25.12 (`apk`). AWG Test пока запускается только в системах с `opkg`, поскольку это ограничение оригинального установщика. Zapret2 из пакетов Routerich предназначен только для `aarch64_cortex-a53` и совместимой версии OpenWrt. Проверяйте, что обычный Zapret не установлен: два компонента одновременно несовместимы.

# Router Service Check

Небольшой скрипт для быстрой проверки доступности сайтов непосредственно с роутера OpenWrt.

## Быстрая проверка

Запусти скрипт командой:

```sh
sh <(wget -O - https://raw.githubusercontent.com/itdoginfo/podkop/refs/heads/main/install.sh)
```

Скрипт запускается прямо из командной строки; это быстрая проверка, а не установка полноценного приложения Site_Checker.

## Полноценное приложение Site_Checker

Также существует полностью реализованная версия **Site_Checker** с интерфейсом LuCI: она отображает доступность сайтов, задержку и HTTP-код и предоставляет настройки проверок.

Проект приложения: [TMN88/Site_Checker](https://github.com/TMN88/Site_Checker)

В README проекта приведены возможности приложения, поддерживаемые версии OpenWrt и инструкции по установке и удалению.

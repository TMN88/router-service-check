# Router Service Check

Набор инструментов для проверки доступности сайтов непосредственно с роутера OpenWrt.

## Site_Checker

**Site_Checker** — приложение для LuCI, которое показывает доступность выбранных сайтов, задержку и HTTP-код. В нём есть обычная HTTP/HTTPS-проверка и дополнительная проверка по списку URL, основанная на подходе из Zapret Manager. Сам Zapret и другие VPN-компоненты это приложение не устанавливает.

Поддерживаются OpenWrt 24.10.x (пакетный менеджер `opkg`) и 25.12.x (пакетный менеджер `apk`) при наличии нужных пакетов в feeds прошивки.

### Установка и запуск

Подключись к роутеру по SSH под пользователем `root` и выполни:

```sh
wget -O /tmp/site-checker-install.sh 'https://cdn.jsdelivr.net/gh/TMN88/Site_Checker@d4f19865f451f47c3355a31b17fade8ddd326950/install.sh' && sh /tmp/site-checker-install.sh
```

После установки открой веб-интерфейс LuCI:

**Services → Site_Checker**

### Важно

Проверка выполняется с самого роутера. Успешный HTTP-запрос не гарантирует полноценное воспроизведение видео или работу всех функций сайта, а ошибка запроса сама по себе не доказывает блокировку.
